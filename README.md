# Unity Systems 🛠️

A collection of modular, ready-to-use systems designed for quick implementation in Unity projects. 

Instead of rewriting core mechanics from scratch for every new project, I am gathering plug-and-play setups here, complete with documentation.

## 📦 Available Systems

Currently available systems in this repository:

*   **[FPS Character Controller](https://github.com/R14LP/Unity-Systems/tree/main/FPS%20Character%20Controller)** - A first-person player controller complete with a comprehensive animation tree and physics settings. Check the `SETUP.md` guide inside its folder for step-by-step setup details and visuals.

*(This list will be updated as new systems are developed.)*

## 🚀 How to Use

Each system is designed as an independent module within its respective folder:
1. Download the folder of the system you need.
2. Copy the folder directly into the `Assets` directory of your Unity project.
3. Follow the step-by-step visual guide in the `SETUP.md` file located inside that system's folder to complete the setup.
